# CHIP-8 Emulator

A CHIP-8 emulator written in C++ using SDL2. The emulator interprets CHIP-8 instructions and displays games in a window.

## How to use
1. Download the latest release from the [Releases](https://github.com/JoeSandifer/CHIP-8/releases/tag/v1.0.0) page.
2. Extract the downloaded zip.
3. Run CHIP-8.exe.
4. Select a CHIP-8 ROM file using the file picker.
5. Make sure SDL2.dll is in the same folder as CHIP-8.exe.

## Features
- Emulates the CHIP-8 system using C++.
- Uses SDL2 for graphics, window management and keyboard input.
- Supports loading ROM files through a Windows file picker.
- Allows CHIP-8 games to be played on a desktop computer.
